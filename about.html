    The Ambition

    I practice accessibility, maintainability, and optimization in my work. I use Agile methodology with emphasis on version control and system blueprinting. My ambition is to share my work and promote myself. On this website you’ll find my projects.

    This is a static website hosted on an AWS S3 bucket. It's easy to update with a simple pipeline. I use VSCode and Github for versioning, Github actions for updating, and AWS Amplify for hosting.

    I use in-house as much as possible. Every html block, CSS line, and artwork piece is made by me. There are moments when I find it hard to adapt, but reinforcing my skillset and mind allow me to overcome obstacles and deliver a quality of work I am proud of.
